## Konfigurieren von Projektseiten im Ghost-Blog

### Seite erstellen & konfigurieren
In der Sidebar Pages auswählen und eine neue Page erstellen.
Benötigter Inhalt:
- Titel wird aus dem Editor übernommen
- Inhalt wird aus dem Editor übernommen inklusive Formatierung und Bilder
- Bild Übersichtskarte: "feature image" hinterlegt. Ohne Bild wird die Seite nicht in der Projektübersicht angezeigt.
- Beschreibung Übersichtskarte/Unterseite: Excerpt-Feld
- URL: Page-URL-Feld. Unter diesem Link ist die Seite erreichbar via website/projects/url.
- Präfix/Titelüberschrift Überschriftskarte: X/Twitter Title wird aus Ghost zweckentfremdet um dieses Feld zu befüllen

### Seite in Projektübersicht anzeigen
Damit die Seite angezeigt wird, muss sie den entsprechenden Tag der Übersichtsseite erhalten.
Dafür sind in Ghost momentan folgende Tags definiert:
- #strategy
- #operations
- #innovation

Nachdem Tags vergeben wurden, muss die Seite via "Publish" veröffentlicht werden und wird danach in der entsprechenden Kategorie der Projektübersicht sichtbar. 
Falls Fehler gefunden werden kann man die Seite jederzeit mit "Unpublish" entfernen und erneut bearbeiten.
